# 🎬 Movie App

A Demo Android Movie App built using **Jetpack Compose** and following clean architecture principles.  
The app allows users to browse movies, view details, and enjoy a smooth modern UI experience.

---

## ✨ Features

- 🎥 Browse trending/popular movies
- 🔍 Search movies
- 📄 Movie details screen
- ⭐ Ratings and overview
- ⚡ Smooth UI with Jetpack Compose
- 📱 Responsive modern design

---

## 🛠 Tech Stack

- **Kotlin**
- **Jetpack Compose**
- **MVVM Architecture**
- **Retrofit**
- **Coroutines**
- **Flow / StateFlow**
- **Navigation Compose**
- **Hilt / Dagger**
- **Coil**
- **Material 3**
